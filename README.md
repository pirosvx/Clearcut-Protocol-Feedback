# Clearcut Protocol — Feedback and Bug Reports

Maintained by **The Creator**. This repository tracks problems and suggestions for the Satisfactory mod **Clearcut Protocol** (internal mod reference: `ClearCutter`).

## Report a problem or share feedback

Open the **Issues** tab, search for an existing report, then choose **New issue**. Select **Bug report** or **Feedback or suggestion** and complete the form.

For an existing report, add useful details in a comment rather than opening a duplicate. You can follow its progress by subscribing to the issue.

Reports and attachments are public. Remove personal information from screenshots and logs.

## Report status

- **needs review**: waiting for initial review.
- **confirmed**: the problem has been verified.
- **needs information**: more details are needed.
- **planned**: an accepted improvement for a future update.
- **in progress**: work has started.
- **fixed**: resolved; the closing comment identifies the release containing the fix.
- **duplicate**: tracked elsewhere; the closing comment links the original report.

A suggestion is not a promise of implementation. Closed issues retain their discussion and resolution.

## About this repository

This is a reporting and documentation repository. Mod source code and game assets are not included.
